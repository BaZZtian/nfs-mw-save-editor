# NFS MW Save Editor — Experimental Switch Community Preview

## Start here

Download Experimental Switch Community Preview 2 on Windows. Extract the entire ZIP and run `NFS_MW_Junkman_Editor.exe`. Keep a separate copy of your original save.

[Download v1.5.0-switch-preview.2](https://github.com/BaZZtian/nfs-mw-save-editor/releases/tag/v1.5.0-switch-preview.2)

This is an **unofficial experimental community fork** of
[sprintstate/nfs-mw-save-editor](https://github.com/sprintstate/nfs-mw-save-editor).
The original editor is maintained by sprintstate. Official builds are available
only from the [upstream releases](https://github.com/sprintstate/nfs-mw-save-editor/releases).

## Switch community download

The [community pre-releases](https://github.com/BaZZtian/nfs-mw-save-editor/releases)
provide a portable Windows preview for the documented raw Xbox 360 / nfsmw-nx
save layout. Extract the entire ZIP and run `NFS_MW_Junkman_Editor.exe`.
No separate Python installation is needed for the portable application.

Switch support remains **experimental**.
The current community build supports native save open/edit/save, money,
reward/Junkman markers, tuning, car-build injection and career-stage changes.
Compatibility with every save version, vehicle or PC/Xbox part index is not
established. Keep an independent known-good save backup.

Use the payload generated by your installation:

```text
<NRO folder>/nfsmw/<XUID>/454107D9/00000001/<profile>/<profile>
```

The final component is the extensionless save file. The `actual` and `anterior`
directories contain automatic copies. Format details and reproducible checks
are in [SWITCH_SAVE_FORMAT.md](docs/SWITCH_SAVE_FORMAT.md).

## Updates and community feedback

Each community release identifies its source commit, supported native-save
layout and validation scope. Compatibility of future upstream features with
native saves requires separate verification.

Switch-specific feedback can be reported through this fork's issue tracker.
When an official release covers the Switch workflow, the community preview
will be marked superseded and point to the official download.
